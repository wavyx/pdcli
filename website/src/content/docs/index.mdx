```bash
npm install -g @wavyx/pdcli
pdcli auth login
pdcli pipeline health
```

  <Card title="Your whole CRM, scriptable" icon="laptop">
    Create, read, update, and delete deals, contacts, organizations,
    activities, products, leads, notes, and more — with `--output
    table|json|yaml|csv`, `--jq` filtering, and deterministic exit codes.
  </Card>
  <Card title="Own your data" icon="seti:db">
    One-command full-account backup with resume. Bulk CSV import. A
    data-hygiene `audit` that finds duplicates, stale deals, and missing
    fields — and can gate your CI.
  </Card>
  <Card title="Secure by default" icon="seti:lock">
    Tokens live only in your OS keychain — never plaintext on disk. The raw
    `api` escape hatch is host-locked to your own Pipedrive domain, so a
    mistyped URL can't leak credentials.
  </Card>
  <Card title="Built for AI agents" icon="rocket">
    JSON everywhere, sysexits codes to branch on, self-describing `--help`,
    and machine-readable docs (`llms.txt`). Claude Code and friends operate
    pdcli end to end.
  </Card>
