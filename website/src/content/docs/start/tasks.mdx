pdcli ships 150+ commands across 28 topics. This page is the shortcut: find the **job**
you're trying to do, and it points you at the command (and the guide that goes deep).

Every command takes the [global flags](/pdcli/automation/output/) `--output`, `--jq`,
`--fields`, `--profile`, and friends. For the exhaustive list of every command and flag,
see the [command reference](/pdcli/reference/commands/).

## Everyday CRM: create, find, update

| I want to… | Command | Learn more |
| --- | --- | --- |
| Create a deal, person, or organization | `pdcli deal create`, `pdcli person create`, `pdcli org create` | [Quickstart](/pdcli/start/quickstart/) |
| Find records (list or filter) | `pdcli deal list`, `pdcli person list`, `pdcli org list` | [Quickstart](/pdcli/start/quickstart/) |
| Search across every entity at once | `pdcli search "acme"` | [Reference](/pdcli/reference/commands/#pdcli-search) |
| Fetch one record by ID | `pdcli deal get 42`, `pdcli person get 17` | [Reference](/pdcli/reference/commands/) |
| Update a field on a record | `pdcli deal update 42 --field "Deal Size=Large"` | [Custom fields](/pdcli/guides/custom-fields/) |
| Delete a record | `pdcli deal delete 42` | [Reference](/pdcli/reference/commands/) |
| See a deal's whole world in one call | `pdcli deal context 42` | [MCP server](/pdcli/guides/mcp/) |

## Deduplicate & reconcile

| I want to… | Command | Learn more |
| --- | --- | --- |
| Resolve a record by an exact field value (create-vs-update primitive) | `pdcli lookup person --by email=jane@acme.com` | [Bulk operations](/pdcli/guides/bulk/) |
| Create-or-update idempotently (no dupes) | `pdcli person upsert`, `pdcli deal upsert`, `pdcli org upsert` | [Bulk operations](/pdcli/guides/bulk/) |
| Merge a duplicate contact into the survivor | `pdcli person merge <losing-id> --into <survivor-id>` | [Bulk operations](/pdcli/guides/bulk/) |
| Merge two organizations | `pdcli org merge <losing-id> --into <survivor-id>` | [Bulk operations](/pdcli/guides/bulk/) |
